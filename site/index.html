Up and Running in 60 Seconds

Three commands. That's it.

Terminal
# Clone and build
git clone https://github.com/nonbinarytechnology-collab/AI-Intelligence-MCP-.git
cd AI-Intelligence-MCP- && npm install && npm run build

# Connect to Claude Code
claude mcp add ai-intelligence-mcp -- node dist/index.js

# Or run as a hosted server
API_KEYS=your-key npm run start:http
